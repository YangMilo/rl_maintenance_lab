설비 한 대를 두고 매일 아침 '생산할까, 정비할까'를 정하는 문제를 강화학습(Q-learning)으로 풀고,
기존 정비 방식, 그리고 동적계획법으로 구한 정답과 비교합니다.

## 결과 한눈에 보기

| 방법 | 하루 평균 이익 |
|---|---:|
| 사후 정비 (고장 나면 고친다) | −0.38 |
| 주기 정비 (8일마다) | 4.11 |
| 상태 기준 정비 (상태 7 이상이면) | 6.99 |
| 강화학습 (5회 평균) | 7.02 |
| 정답 (동적계획법) | 7.07 |

시나리오 200개 × 5,000일로 평가했고, 모든 방법이 같은 시나리오 번호를 씁니다.
강화학습은 열화 확률을 모른 채 정답의 99%에 닿았고, 성수기에는 더 버티고 비수기에는 일찍 정비하는 정책을 스스로 찾았습니다.
